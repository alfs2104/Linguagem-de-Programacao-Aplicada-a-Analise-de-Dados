# Aula 01 — Fundamentos de Python 🐍

Primeira aula da disciplina **Linguagem de Programação Aplicada à Análise de Dados**, com foco nos fundamentos da linguagem Python e na construção dos primeiros programas.

## 📚 Conteúdos abordados

* Variáveis e atribuição de valores
* Tipos de dados (`str`, `int` e `float`)
* Entrada de dados com `input()`
* Saída de dados com `print()`
* Conversão de tipos com `int()` e `float()`
* Operadores matemáticos
* Ordem de precedência das operações
* F-strings
* Caracteres especiais (`\n`, `\t`, `\"` e `\\`)
* Formatação de números
* Cálculo de porcentagens
* Operações matemáticas em Python

## 🧮 Exercício desenvolvido

### Calculadora básica

Foi desenvolvido um programa em Python capaz de receber dois valores numéricos e realizar as seguintes operações:

* Soma
* Subtração
* Multiplicação
* Divisão
* Divisão inteira
* Resto da divisão
* Potência
